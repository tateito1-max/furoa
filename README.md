# ダンジョンフロア生成機

不思議のダンジョン風のフロア（100×100マス）をブラウザ上で生成・表示する単一HTMLツールです。
`index.html` をブラウザで開くだけで動きます（サーバー不要・依存ライブラリなし）。

- 四角 = 地形（壁・部屋の床・通路）、丸 = オブジェクト（アイテム・モンスター・罠・階段・店主・商品・初期位置）
- フロアの外周は常に絶対壁。内側の壁は「普通の壁 / 硬い壁 / 絶対壁 / 水路 / 空中」からフロア単位で選択
- 上部の「⚙ 設定を隠す / 表示」で設定パネルを折りたためます。幅800px以下（スマホ）では初期状態で非表示になり、マップは画面幅に合わせて縮小表示されます
- 同じシード＋同じ設定なら同じフロアが再現されます。設定はURLの `#` 以降に保存されるので、URLを共有すれば同じフロアを開けます

## フロアタイプ

| タイプ | 内容 |
| --- | --- |
| 通常フロア | マップを区画に分け、各区画に部屋を置いて通路で接続 |
| 大部屋 | フロア全体が1つの部屋 |
| 大部屋（柱の間） | 大部屋に柱が等間隔に並ぶ |
| 大部屋迷路 | フロア全体が迷路 |
| 太陽フロア | 中央の大きな部屋から周囲の小部屋へ通路が伸びる |
| O形フロア | 部屋が環状に一筆書きで接続される |
| ゼルダフロア | 同サイズの部屋が格子状に並び（有無はランダム）、短い通路で接続 |

## パラメータ

- **部屋**: 部屋数（最小〜最大）、幅・高さ（最小〜最大）、角の丸い部屋 / 柱の間 / 迷路部屋の出現確率、迷路のループ率、中央の部屋の大きさ（太陽）、通路の長さ（ゼルダ）
- **通路**: 曲がり具合（0 = できるだけ直線、100 = 大きく蛇行）、追加通路の確率（全域木に加えるループ通路）
- **オブジェクト**: 階段の数、アイテム・モンスター・罠の数、店の出現率、モンスターハウスの出現率
- **表示**: マスの大きさ、グリッド線、記号表示、画面幅に合わせて縮小

## 出力

- **PNG保存**: 表示中のキャンバスを画像として保存
- **JSON保存**: 地形（1行1文字列）、部屋の一覧（座標・種類・役割・ドア位置）、オブジェクト一覧、使用パラメータ
- **テキスト表示**: ASCII マップ（`#` 外周、`.` 部屋の床、`,` 通路、壁は素材ごとに `# % @ ~ _`、オブジェクトは `> P i m t K $`）

## 生成ロジックの概要

1. フロアタイプごとに部屋を配置（部屋の種類は確率で「角丸 / 柱の間 / 迷路」を決定）
2. 接続グラフを作る（通常: 最小全域木＋近傍への追加通路、太陽: 中央への星型接続、O形: 環状、ゼルダ: 隣接部屋の全域木＋追加接続）
3. 部屋の向かい合う辺にドアを決め、方向付きダイクストラで通路を掘る（曲がり具合はコストのノイズと転回ペナルティで制御。他の部屋や部屋の壁沿いは避ける）
4. 到達できない部屋があれば最寄りの部屋へ追加で接続
5. 開始部屋・階段・店（入口の最も少ない部屋。商品は 2×3〜3×4 の長方形ブロックとして隙間なく配置し、店主は入口に立つ）・モンスターハウス・アイテム/モンスター/罠を配置（罠は部屋の入り口＝通路に接する床には置かない）

`index.html` 内の `generateFloor(params)` はUIから独立しているので、Node.js からも `require` して利用できます。
